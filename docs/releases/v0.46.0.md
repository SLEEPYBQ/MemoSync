Settings now shows shortcuts on a keyboard. Click a highlighted key or a binding in the list to record its replacement. Removing the last binding leaves that action unassigned. Sidebar chat jumps, new chats and adding a project also have Ctrl+Alt defaults. An upgrade keeps existing custom bindings; a conflict on any digit keeps the entire new sidebar-jump alternative unassigned.

### Chats and memory

- Pressing Stop keeps the partial assistant reply. An incompatible queued slash command no longer blocks the messages behind it.
- Timing out while waiting for one command's acknowledgement no longer disconnects the shared socket.
- The app remembers device-local UI preferences across restarts.
- File drift detection catches changes even when the file size and modification time are unchanged. Permanently deleting a memory candidate now also removes legacy copy lineage.

### Model credentials

Saved API keys move to the operating system's credential vault. Existing plaintext credentials are removed only after successful migration. If you move the data directory or restore it on another machine, enter your saved keys again. Native accounts and environment-supplied keys do not require a vault entry.

### Downloads

Choose the macOS DMG or ZIP for your chip (Apple silicon or Intel), the Windows x64 installer or ZIP, or the Linux x64 AppImage or Debian package. `SHA256SUMS` lists all eight packages. Updates are installed manually; macOS packages are ad-hoc signed and not notarized, and Windows packages are not publisher-signed.
