Desktop updates now happen inside the app. Settings → About checks for a new release on demand, shows download progress, verifies the package against the published checksums, and installs it only after you confirm. Installed Windows and Linux AppImage builds update in place; macOS and Debian builds open a verified package for the final step. Nothing downloads or installs automatically, and quitting never triggers an installation.

### Chats and memory

- Queued messages keep their order and survive restarts. A queued prompt is removed only after it is durable in the transcript, so a failed or interrupted start never loses or repeats it.
- Interrupting a memory turn saves the original text and provider settings; resuming keeps plan mode and refuses a changed connection instead of sending the continuation elsewhere.
- Answers to agent questions stay editable after a rejected tool response, and sending the same message twice while waiting for acknowledgement is no longer possible.
- Hiding a project now stops its sessions and finishes memory cleanup; reopening it continues the original chats instead of leaving them stuck.
- Undoing a memory import and importing it again no longer produces contradictory active memories, withdrawn revisions can no longer bypass review, and team rules without an expiry no longer get one invented.

### Files and projects

- The Files editor keeps unsaved edits in memory across panel and project switches. Saving preserves the file's encoding, BOM and line endings, and refuses to overwrite contents that changed on disk since the snapshot you edited.
- Cancelling Quit with unsaved edits no longer stops the backend behind your back; the app keeps running and the drafts remain editable.
- Switching between projects no longer shows the previous repository's Git state, and generating a commit message or committing always targets the chat where the operation started.
- Attachments picked on the landing screen upload correctly the first time a discovered project is opened, and a late send acknowledgement can no longer redirect you away from the conversation you navigated to.

### Backups and exports

- Exporting data or a chat's offline page never overwrites an earlier export: every archive and transcript directory gets its own unique name, even within the same minute or for same-named chats. Destinations inside the data being archived are rejected before any folder is created.

### Downloads

Choose the macOS DMG or ZIP for your chip (Apple silicon or Intel), the Windows x64 installer or ZIP, or the Linux x64 AppImage or Debian package. `SHA256SUMS` lists all eight packages. macOS packages are ad-hoc signed and not notarized, and Windows packages are not publisher-signed.
