MemoSync v0.45.0 brings the desktop app to Windows, Linux and Intel Macs, alongside Apple silicon.

### Desktop platforms

- **Windows x64:** a per-user installer and a ZIP containing `MemoSync.exe`.
- **Linux x64:** an AppImage and a Debian/Ubuntu `.deb` package.
- **macOS:** separate DMG and ZIP downloads for Apple silicon (`arm64`) and Intel (`x64`).

Each package includes Bun 1.4.4. Agent CLIs remain separate: install and authenticate the agents you want to use, then select them in Settings → Models. Windows supports the embedded terminal through ConPTY, Windows CLI installation directories and npm launchers, and workspace paths containing spaces or Unicode. Linux and Windows use their native window controls.

### Agent-requested files

Claude and OpenCode can now request read-only workspace files in the originating MemoSync window, joining the existing Codex and Pi support. Requests retain durable receipts and distinguish acceptance from actual presentation. Cancelled and completed turns cannot reuse another turn's window. File actions also work with managed memory disabled.

### Installation

Choose the download matching your OS and architecture. On macOS, drag MemoSync to Applications. On Windows, run the `Setup.exe` installer or extract the ZIP. On Debian/Ubuntu, install the `.deb`; the AppImage is available for other compatible Linux distributions.

The macOS packages are ad-hoc signed and not notarized. Windows publisher signing is not configured. Existing server-backed projects, settings, conversations and memory stay in the user's MemoSync data directory. Only one app or source server may use that directory at a time. Updates are installed manually.

`SHA256SUMS` covers every desktop download. Release builds exercise the packaged apps with isolated synthetic data; they do not make live model calls.
