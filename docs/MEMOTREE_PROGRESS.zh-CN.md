# MemoTree 实现进度与后续工作

## 当前结论

MemoTree 已有可使用的主题目录、树形组织、手动与自动归类，以及基于已有记忆生成主题树的预览和应用流程。它仍处于基础能力阶段：主题摘要、基于摘要的层次检索、子主题拆分建议和完整操作撤销尚未交付；初始化及跨功能的端到端验收也需要补齐。当前不宜用一个百分比表示完成度。

主题是组织层：每条记忆最多关联一个用户主题；它与记忆的个人／项目／会话范围和审阅状态分开。独立的 `topic_id` 不替换旧 `topic` 字段，旧字段仍保留原语义；旧记忆默认未分类，而不是自动迁入主题目录。

## 主题树初始化：已有预览与应用，仍需完善

最新代码增加了模型辅助初始化，入口在看板主题目录。用户可以查看配置的模型、生成主题和归类预览，确认后应用，或者取消。服务端只选取**当前有效、非敏感、未分类**的记忆，连同现有主题目录发给所配置的模型；建议创建新主题，不会直接把记忆归到现有主题。用户应根据所配置模型的数据处理方式决定是否运行。

服务端校验建议的主题和归类，限制单次最多 100 个新主题；预览本身不修改数据。生成期间或应用前相关快照发生变化会拒绝，应用时在事务中创建主题并归类。预览仅保存在服务进程内，30 分钟后过期，重启后也需重新生成。详见 [初始化服务](../src/server/memory/topic-initialization.ts) 和 [目录界面](../src/client/components/memory/MemoryTopicDirectory.tsx)。

当前预览只能整体确认或取消，不能逐条编辑主题、父子关系和归属；也没有初始化复合操作的用户可用撤销。模型可能不分类不确定条目，现有实现没有分批和大规模记忆库处理策略。初始化相关自动化测试覆盖了预览不写入、应用、快照冲突、模型失败和模型信息接口；真实模型效果、界面流程和隐私边界仍需实际验收。

## 节点之间如何关联

当前看板使用的是 [主题图谱](../src/client/lib/memoryGraph.ts)，连线表示**组织关系**，不是模型算出的语义相似度：

- **根节点 → 根主题 / 未分类：** 在“全部”视图中，根主题和“未分类”连接到根节点。主题创建或移动到根目录后成为根主题；未归类的有效记忆或候选挂在“未分类”下。
- **父主题 → 子主题：** 依据主题保存的 `parent_id` 连线。创建子主题、移动主题或应用初始化建议后出现；移动后按新的父子关系展示。双击某个主题后，图谱展示该主题、后代及直属父主题，用于保留上下文。
- **主题 → 记忆：** 依据记忆的 `topic_id` 连线。用户手动归类、模型对新候选推荐已有主题、或用户确认初始化方案后，记忆才挂到对应主题；无主题时挂在“未分类”。同一主题下的记忆因此共享父节点，但这不表示它们彼此有语义关系。

图谱中只画通过当前范围、状态和搜索等筛选的有效记忆与候选，归档记忆不出现在图中；主题结构与记忆适用范围各自独立。悬停节点时会突出它以及通过当前图中连线直接相邻的节点。连线和位置由图谱布局计算，距离远近不代表相关程度。

记忆系统还单独存储记忆之间的关系，例如冲突（捕获发现冲突时）、修订（创建修订候选时）、派生（从来源创建记忆时）和相似（在冗余检查中选择保留两条时）。这些关系用于相应的审阅或维护流程；**当前主题图谱只生成上述组织连线，不绘制记忆之间的关系线**。代码中另有按范围构建的图谱函数能够生成关系线，但当前看板使用的不是它；不能据此认为主题图谱已经展示了记忆间的语义关联。参见 [关系类型](../src/server/memory/types.ts)、[关系写入](../src/server/memory/MemoryStore.ts) 和 [维护操作](../src/server/memory/maintenance.ts)。

## 接下来的重点：检查和完善现有功能

当前先不扩展主题摘要、层次检索、自动拆分或其他新能力，优先检查已实现流程：

1. **主题树与图谱：** 检查创建、移动、改名、删除、子树筛选、双击聚焦、目录折叠及拖拽后的图谱同步；验证深层路径、同名主题的现有全局去重规则，以及刷新重启后的表现。
2. **手动与自动归类：** 检查候选审阅、批量部分失败及重试、目标主题被删除、用户并发调整和敏感候选保护；确认分类不会改变内容、范围或审阅状态。
3. **初始化：** 检查模型不可用、非法输出、预览过期或内容变化、事务失败和取消流程；用真实模型和不同规模的合成数据手动验证预览与应用，并确认发送数据的范围。
4. **数据与恢复：** 检查旧库升级、分类历史、导出回读、敏感数据擦除和跨项目／会话隔离；明确当前仅有主题移动的存储层撤销，避免误以为已有完整撤销界面。
5. **交互验收：** 手动验证主题选择器、删除影响提示、图谱导航、空状态、错误提示以及中英文文案；根据发现的问题修复现有流程。

主题摘要、层次检索、拆分建议、主题合并及完整复合操作撤销属于原设计中的未来方向，目前不安排扩展。
