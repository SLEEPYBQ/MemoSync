Co-manage memory with your coding agent across sessions.

Coding agents keep memory, but you rarely see it. MemoSync is a local workbench that shows what your agent remembers, lets you decide what it keeps and what it uses, and checks afterwards whether it followed it.

It learns while you work.

MemoSync notices what is worth remembering in the conversation and proposes it as memory.

  1. Learn
  2. Review
  3. Persist
  4. Choose
  5. Follow
  6. Check
  7. Automatic
  1. Learn: MemoSync notices what is worth remembering in the conversation and proposes it as memory.
  2. Review: nothing is kept until you say so. Every proposed change waits for review.
  3. Persist: context clears, memory stays. The memory board carries what matters into the next session.
  4. Choose: before a turn starts, you confirm which memories go in and how they will be used.
  5. Follow: replies cite the memories they apply, and you can stop the agent when it drifts.
  6. Check: a separate audit marks each memory as shaped, violated, not applicable or no visible effect.
  7. Automatic: safe changes apply on their own; sensitive ones wait; the audit speaks up only when something broke.

two minutes

Start on your machine.

  1. Install Bun 1.3.5 or newer, and have Claude Code or Codex signed in — or an API key from any provider.
  2. Run the commands. MemoSync opens at localhost:3210.
  3. Connect a model in Settings → Models, open a project, and send a task.
git clone https://github.com/SLEEPYBQ/MemoSync.git
cd MemoSync
bun install
bun run build
bun run start

MemoSync remembers so the next session doesn't start from zero.
